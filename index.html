BimMcpSuite Privacy Policy · 개인정보처리방침

Version 1.0 · Effective 2026-10-27 · 시행일 2026-10-27

English · 한국어

English

BimMcpSuite ("BMS") is an add-in for Autodesk Revit, Navisworks and AutoCAD that lets an AI assistant you choose (an MCP client) work with the model open on your computer. This policy explains what BMS does with data.

Local by default

  • BMS opens one network listener bound to 127.0.0.1 (your own computer only) on a random port. Every request must carry a random per-session secret readable only by your Windows user. Requests that look like they come from a web page are rejected.
  • BMS has no cloud service and no update check. It sends nothing over the internet unless you turn usage statistics on, or you use the marketplace edition's purchase check (both described below).
  • Files kept on your computer: logs (%LOCALAPPDATA%\BMS\logs), an audit log of every model-changing call (%LOCALAPPDATA%\BMS\audit), trial state and a random install id (%LOCALAPPDATA%\BMS\state.json) and optional settings (%APPDATA%\BMS\config.json). You can delete them at any time.

Usage statistics (opt-in, off by default)

  • You are asked once on first run; the default answer is No. Declining does not limit any feature. Change it any time from Start menu > BimMcpSuite > Usage statistics, or BMS.exe --telemetry on|off.
  • If on, BMS sends at most one batch a day over HTTPS containing only: a random install id, BMS version, host application and version, Windows major version, UI language, date, per-tool call/success/failure counts, error codes from a fixed list, a duration bucket, write/preview counts and the trial day.
  • It never sends project names, file paths or names, element/family/view/sheet names, parameter values, AI prompts or responses, user/PC/domain names, exception text or stack traces.
  • You can read exactly what will be sent in %LOCALAPPDATA%\BMS\telemetry\next.json. Unsent batches are deleted after 7 days; turning statistics off deletes pending data.
  • Company IT can disable it: registry HKCU\Software\BMS\TelemetryDisabled=1, environment variable BMS_TELEMETRY=0, or "telemetry": "off" in config.json.
  • Version 1.0 ships with no statistics server configured, so nothing is sent even when statistics are on. If a server is added later, this policy will be updated first.

Purchase check (marketplace edition only)

The Autodesk App Store edition asks Autodesk's Entitlement API whether your Autodesk account owns the app. It sends your Autodesk user id and the app id to Autodesk; Autodesk handles them under its own privacy statement. If the check cannot run (offline), all tools keep working for 7 days after the last successful check.

Your AI assistant

Whatever BMS returns to your AI assistant (element data, parameters, images you request) goes to your AI provider under that provider's terms, not this policy. Do not connect an assistant you do not trust to confidential models.

Support and feedback

BMS.exe --support-bundle and BMS.exe --feedback create files on your desktop. Nothing is sent automatically; you decide whether to email them. If you email us, we use your address and message only to answer you and delete them when the matter is closed.

Contact

Support and privacy questions: hjparkbim@gmail.com

한국어

BimMcpSuite(이하 "BMS")는 Autodesk Revit·Navisworks·AutoCAD 애드인으로, 사용자가 고른 AI 도우미(MCP 클라이언트)가 내 PC에 열린 모델을 다룰 수 있게 합니다. BMS 개발자(이하 "개발자")는 「개인정보 보호법」에 따라 아래와 같이 개인정보를 처리합니다.

1. 처리하는 개인정보 항목과 목적

  • 사용 통계(선택, 기본 꺼짐): 임의 설치 번호, BMS·호스트 프로그램 버전, Windows 주 버전, 화면 언어, 날짜, 도구별 호출·성공·실패 횟수, 정해진 오류 코드, 소요시간 구간, 쓰기·미리보기 횟수, 체험 일차. 목적은 기능 개선과 오류 파악입니다. 프로젝트명·파일 경로·요소 이름·파라미터 값·AI 대화 내용·사용자/PC 이름은 수집하지 않습니다. 1.0 배포본은 통계 서버가 지정돼 있지 않아 통계를 켜도 아무것도 전송되지 않습니다.
  • 구매 확인(마켓판만): Autodesk 사용자 id와 앱 id를 Autodesk에 보내 구매 여부를 확인합니다. 이 정보는 개발자에게 오지 않으며 Autodesk의 개인정보처리방침에 따라 처리됩니다.
  • 문의 메일: 사용자가 보낸 메일 주소와 내용. 답변 목적으로만 씁니다.

로그·감사 기록·설정 파일은 사용자 PC에만 저장되고 개발자에게 전송되지 않습니다.

2. 보유기간과 파기

  • 사용 통계: 받은 날부터 1년 보관 후 삭제합니다. PC에 남은 미전송분은 7일 뒤 자동 삭제되고, 통계를 끄면 즉시 삭제됩니다.
  • 문의 메일: 문의가 끝나면 삭제합니다.
  • 전자 파일은 복구할 수 없는 방법으로 삭제합니다.

3. 제3자 제공·처리위탁·국외 이전

개인정보를 제3자에게 제공하거나 판매하지 않습니다. 처리위탁은 없습니다. 마켓판 구매 확인은 사용자가 Autodesk(미국)에 직접 조회하는 방식이며, 개발자가 정보를 넘기지 않습니다.

4. 이용자의 권리와 행사 방법

  • 사용 통계는 언제든 끌 수 있습니다: 시작 메뉴 > BimMcpSuite > Usage statistics, 또는 BMS.exe --telemetry off.
  • 보낼 내용은 %LOCALAPPDATA%\BMS\telemetry\next.json에서 직접 확인할 수 있고, BMS.exe --telemetry new-id로 설치 번호를 새로 받을 수 있습니다.
  • 열람·정정·삭제·처리정지 요청은 아래 메일로 하시면 지체 없이 처리합니다.

5. 안전성 확보 조치

BMS는 내 PC 안(127.0.0.1)에서만 통신하고, 세션마다 바뀌는 비밀값으로 요청을 확인합니다. 통계는 HTTPS로만 보내며, 경로·파일·메일처럼 보이는 문자열이 섞인 기록은 저장 전에 버립니다.
